# SaveVideo - موقع تحميل فيديوهات تيك توك وإنستغرام بدون علامة مائية

موقع احترافي وآمن لتحميل فيديوهات تيك توك وإنستغرام بدون علامة مائية مع إمكانية اختيار الجودة.

## المميزات

- 📥 تحميل فيديوهات من تيك توك وإنستغرام بدون علامة مائية
- 🎯 اختيار جودة التحميل (360p, 480p, 720p, 1080p, أفضل جودة)
- 🎵 دعم تحميل صيغ متعددة (MP4, WEBM, MP3)
- 🔒 حماية قوية ضد جميع الثغرات المعروفة
- ⚡ واجهة سريعة وسهلة الاستخدام
- 📱 تصميم متجاوب يدعم اللغة العربية (RTL)
- 🧹 حذف تلقائي للملفات بعد ساعة واحدة

## protecciones الأمنية المطبقة

### طبقة الحماية الأولى: رؤوس HTTP الآمنة (Helmet)
- سياسة أمان المحتوى (CSP) لمنع تحميل سكريبتات خبيثة
- Strict-Transport-Security (HSTS) لإجبار استخدام HTTPS
- X-Frame-Options: DENY لمنع هجمات النقر المختلس (Clickjacking)
- X-Content-Type-Options: nosniff لمنع تخمين نوع المحتوى
- Referrer-Policy لحماية معلومات الإحالة

### طبقة الحماية الثانية: حماية المدخلات
- XSS-Clean لتنظيف جميع مدخلات المستخدم من أكواد خبيثة
- express-mongo-sanitize لحماية من حقن قواعد بيانات NoSQL
- hpp لحماية من تلوث معاملات HTTP (HTTP Parameter Pollution)
- إزالة البايتات الفارغة (null bytes) من جميع المدخلات
- التحقق من صحة الروابط والنماذج باستخدام express-validator

### طبقة الحماية الثالثة: تحديد المعدل (Rate Limiting)
- تحديد 100 طلب لكل عنوان IP كل 15 دقيقة ( geral)
- تحديد 10 طلبات تحميل لكل عنوان IP كل دقيقة
- منع هجمات الحرمان من الخدمة (DDoS) والهجمات القسرية

### طبقة الحماية الرابعة: CORS والأمن العام
- التحقق من أصل الطلبات (Origin validation)
- حظر المصادر غير المصرح بها
- معالجة أخطاء آمنة دون تسريب تفاصيل النظام
- إيقاف تشغيل Graceful عند إغلاق الخادم

## تنبيه قانوني مهم

هذا الموقع مصمم لأغراض تعليمية وشخصية فقط. المستخدم مسؤول عن:
- احترام حقوق الملكية الفكرية لمالكي الفيديوهات
- عدم تحميل محتوى محمي بحقوق النشر دون إذن
- الامتثال لشروط خدمة تيك توك وإنستغرام
- استخدام الموقع لأغراض قانونية فقط

الموقع لا يستضيف أي محتوى فيديو على خوادمه، بل يوفر أداة للوصول إلى الفيديوهات المتاحة علناً.
